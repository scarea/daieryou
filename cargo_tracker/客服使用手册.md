# Ethiopian Cargo 批量查询工具使用手册

## 这个工具用来做什么

把一批 Ethiopian Cargo 提单号放到 Excel 里，工具会自动查询并生成一个结果 Excel。

## 使用前准备

你会拿到这些文件：

- `EthiopianCargoTracker.exe`
- `input_template.xlsx`

把这两个文件放在同一个文件夹里。

## 第一步：填写提单号

打开 `input_template.xlsx`。

第一列填写提单号，从第二行开始填：

| AWB |
| --- |
| 071-61046882 |
| 071-xxxxxxxx |

填写完成后保存 Excel，然后关闭 Excel。

注意：

- 不要删除第一行表头 `AWB`。
- 提单号放在第一列。
- 一行只放一个提单号。

## 第二步：运行查询

双击运行 `EthiopianCargoTracker.exe`。

打开窗口后：

1. 点击 `选择文件`，选择填写好的 `input_template.xlsx`。
2. 点击 `选择保存位置`，选择结果 Excel 保存在哪里。
3. 点击 `开始查询`。

运行后请等待，不要重复打开多个工具窗口。

工具会逐票查询。为了避免给网站造成压力，每票之间会随机等待几秒钟，所以批量查询会需要一些时间。

## 第三步：查看结果

查询完成后，会生成结果 Excel。

结果文件一般在 `output` 文件夹里，文件名类似：

```text
ethiopian_cargo_result_20260513_153000.xlsx
```

结果 Excel 有 3 个 sheet：

- `查询汇总`：看每个提单号是否成功。
- `航班计划`：看航段、航班号、日期、状态。
- `货物轨迹`：看货物的历史节点。

## 常见问题

### 查询失败怎么办？

先看 `查询汇总` 里的 `错误信息`。

常见原因：

- 提单号填错。
- 网站暂时打不开。
- 网站返回太慢。
- 网站触发限流或验证码。

可以稍后再查，不要频繁重复运行。

### 为什么查询很慢？

这是正常的。工具会故意随机等待，避免短时间大量请求网站。

### 能不能同时开多个工具一起跑？

不建议。多个工具同时跑会增加网站压力，也更容易失败。

### 中途断了怎么办？

工具每查完一票都会保存一次结果。可以先查看已经生成的结果 Excel，再决定是否重新查询剩余提单号。
